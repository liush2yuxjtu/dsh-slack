安装指南

把 Thread 加入你的 DSH。

从明确的 GitHub 仓库打包，安装到 Web profile。

1. 核对宿主版本

需要 Node.js 24.9.0 或更高版本，以及 DSH 0.2.2-rc.1。已测试上游提交 fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159。

先在宿主设置中配置 DeepSeek provider 与 API 凭据。密钥由宿主管理。

2. 打包并安装

git clone https://github.com/liush2yuxjtu/dsh-slack.git
cd dsh-slack
npm pack --ignore-scripts
dsh plugin --profile web add "$PWD/dsh-slack-0.1.0.tgz"
dsh web

在 DSH Plugins 中启用 bundle。此流程安装的是 liush2yuxjtu/dsh-slack，包版本为 0.1.0。

3. 验证第一段对话

  1. 在「对话」输入框发送一个新任务。
  2. 在右侧 Thread 回复，确认它继续当前任务。
  3. 创建另一个任务，再返回第一个会话。刷新后检查历史仍存在。

需要排查？

没有界面时，检查 Web profile 和 bundle 启用状态。没有模型回复时，切换「原生 DSH」检查宿主的 provider 和凭据。只有模型写入原生待办后才会显示 TODO 计数。

DSH 插件 API 尚未稳定。升级宿主后，需重新验收兼容性。
