会话与待办教程

新任务放左边，
继续聊在 Thread。

两个输入框对应两种操作。选择正确的入口，就能保持任务上下文。

创建独立会话

在「对话」列表下方输入「帮我规划一次产品发布」。发送后，DSH Slack UI 创建一个新 session，并把它加入历史列表。然后在同一位置发送「帮我筹备工作坊」，它会成为另一个任务。

在同一个 Thread 续聊

选中发布任务，在右侧 Thread 的输入框发送「截图已经准备好了，更新待办」。这条消息沿用发布 session。不要在列表输入框发送这条续聊消息，因为那里会创建新会话。

理解标题、摘要与 TODO

标题来自 DSH 会话元数据。摘要来自已提交的助手正文。推理内容和未完成的流式片段不会成为摘要。TODO 进度来自原生 todo/write 事件，与右侧完整任务面板一致。没有任务的会话不会显示编造的进度。

刷新与返回原生界面

刷新后，由宿主持久化恢复当前会话。点击「原生 DSH」可访问 Settings 和 Plugins，点击「打开 DSH Slack」返回。切换时保留未发送的新任务草稿。

上下文的边界

同一 Thread 沿用同一 session 的上下文。此版本没有实现跨 session 的频道记忆，也没有多人频道或仅 @deepseek 触发机制。
