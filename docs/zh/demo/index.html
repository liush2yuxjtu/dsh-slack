真实 API 实机录屏

看任务如何成为 Thread。

创建两个独立会话，回到发布任务并续聊，让待办从 1/3 更新到 2/3。

完整原片 · 25.87s · Chromium · GPT Work Linux · DeepSeek Flash

录屏中的操作

  1. 开始「规划发布」，模型写入三项待办，第一项完成。
  2. 开始「筹备工作坊」，使用另一个独立 session。
  3. 回到发布 Thread，继续回复，将准备截图标记完成。
  4. 切换任务再返回，展开原生 TODO，确认进度保留为 2/3。

本页录屏保留此前版本的界面。首页截图展示本次界面修复。

只想看 8 秒？

短片展示重新打开已有 Thread 和展开待办。它不表示模型在 8 秒内完成了整项任务。

如何确认是真实 API？

两种语言各有 6 次官方 HTTP 200 响应，记录包含 response ID、usage 和原生工具调用。录屏无加速，无预置助手回复，也无 mock 模型。
