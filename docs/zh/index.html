从任务到结果

01

新消息，新会话

列表下方的输入框为每条新任务创建独立 session。不同任务各自保留历史。

02

在 Thread 里继续

选中任务后，在右侧输入框回复。当前 session 保留此前对话与工具上下文。

03

进度跟着任务走

会话入口展示助手摘要和真实 TODO 完成数，右侧可展开完整原生清单。

沿用原生能力

工具、Markdown、待办。
都留在对话里。

插件复用 DSH 原生消息渲染器、工具调用和输入框。会话由宿主持久化，刷新后可继续。

点击「原生 DSH」访问 Settings 和 Plugins，再返回线程界面，未发送的草稿会保留。

这是哪一个 DSH Slack？

这是 liush2yuxjtu/dsh-slack，提供 Slack 风格的 DSH 会话界面。不连接 Slack 服务，不需要 Slack 账号。当前版本不包含多人频道、仅 @deepseek 触发或跨会话频道记忆。
