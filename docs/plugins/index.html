会话卡片显示原生 TODO 进度与最新已保存助手回复。

Session cards with native TODO progress and the latest saved assistant reply.

dsh plugin --profile web add dsh-sidebar-history@0.2.3
dsh web

遥测默认关闭。测试事件不代表真实用户量；未单独证明与其他布局插件的组合兼容性。

Keep independent tasks in separate threads

DSH Slack UI

为不同任务保留各自的 Thread 与上下文。

v0.1.0 · 2896121

Slack 风格的 DSH 会话、Thread 续聊、摘要与原生 TODO 进度。

Slack-style DSH sessions, contextual thread replies, summaries and native TODO progress.

dsh plugin --profile web add 'git+https://github.com/liush2yuxjtu/dsh-slack.git#289612132d17e87acc761c5c336eee1af0f5cf45'
dsh web

不连接 Slack 服务；与 Channels 二选一。每条根消息创建新 Session，Thread 回复继续当前 Session。

Not a Slack service integration. Choose this or Channels. Root messages start sessions; thread replies continue them.

Discuss first, mention DeepSeek for action

DSH Channels

正常频道聊天，需要执行时才 @deepseek。

v0.1.0 · a6662da

频道讨论、持久 Mission Thread 与仅明确提及时执行 Agent。

Channel chat and persistent mission threads with explicit mention-only execution.

dsh plugin --profile web add 'git+https://github.com/liush2yuxjtu/dsh-channels.git#a6662dafc209e7ae7d39d35dc24a59515acfd797'
dsh web

可信 Host 的 Alpha。频道邀请不隔离 Host owner 的其他会话权限；普通 Thread 回复不调用模型。

Trusted-Host alpha. Invitations do not isolate wider Host-owner access. Ordinary thread replies do not invoke the model.

Find and preview saved HTML artifacts

DSH Artifacts

搜索并打开已有的本地 HTML 成果。

v0.1.3 · 9826d31

只读本地 HTML 成果库，支持搜索、标签和交互预览。

Read-only local HTML library with search, tags and interactive preview.

dsh plugin --profile web add 'git+https://github.com/liush2yuxjtu/dsh-artifacts-extension.git#9826d31d7838a468e54881d11e4f5f3970d29c29'
dsh web

当前0.1.3需要已配置的 artifact-store 和本地缓存。创建、存储、Tweaks 的三个外部 skills 未随包交付；多类型编辑器尚未发布。

Requires a configured artifact-store and local cache. Creation, storage and Tweaks skills are external. The new multi-type editor is not released.

在 DSH Discover 中安装

Plugins → Experimental plugins → 开启 Custom plugin indexes → Discover → Add index source，粘贴：

https://liush2yuxjtu.github.io/dsh-slack/plugins/index.json

查看安装确认中的版本与来源。npm 裸名 dsh-slack 和 dsh-channels 不代表本作者的仓库；使用本页的完整 Git 地址。
