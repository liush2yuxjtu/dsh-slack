INSTALLATION

Add threads to your DSH.

Pack this GitHub repository and install it into your Web profile.

1. Check the host version

Use Node.js 24.9.0 or later and DSH 0.2.2-rc.1. The tested upstream revision is fcc0ad462172522aaf5c93a7b2e01f6b9f0b0159.

Configure the DeepSeek provider and API credential in the host settings. The host manages the key.

2. Pack and install

git clone https://github.com/liush2yuxjtu/dsh-slack.git
cd dsh-slack
npm pack --ignore-scripts
dsh plugin --profile web add "$PWD/dsh-slack-0.1.0.tgz"
dsh web

Enable the bundle in DSH Plugins. This installs liush2yuxjtu/dsh-slack, package version 0.1.0.

3. Check your first conversation

  1. Send a new task in the Chats composer.
  2. Reply in the Thread and confirm it continues that task.
  3. Create a second task, then return to the first. Reload and check that its history remains.

Need to troubleshoot?

If the UI is missing, check the Web profile and enabled bundle. If the model does not reply, open Native DSH and check the host provider and credential. TODO counts appear after the model writes native tasks.

The DSH plugin API is pre-stable. Recheck compatibility after upgrading the host.
